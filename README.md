# Gerenciador de Podcasts

Projeto de estudo desenvolvido durante o bootcamp da **DIO (Digital Innovation One)**.

A aplicação foi desenvolvida com **Node.js e TypeScript**, tendo como proposta o gerenciamento e consulta de informações relacionadas a episódios de podcasts.

## Sobre o projeto

Este projeto foi desenvolvido acompanhando as videoaulas do bootcamp, reproduzindo os exemplos apresentados pelo professor e praticando os conceitos demonstrados durante as aulas.

O objetivo principal foi ter contato com o desenvolvimento backend, organização de código e criação de uma aplicação para gerenciamento de dados.

## Funcionalidades

* Listagem de episódios de podcasts
* Consulta de episódios
* Filtragem de episódios

## Tecnologias

* Node.js
* TypeScript
* TSX
* TSUP

## Estrutura do projeto

A aplicação possui uma organização dividida em diferentes responsabilidades:

* `controllers` — gerenciamento das requisições
* `models` — definição dos modelos utilizados
* `repositories` — acesso e organização dos dados
* `routes` — definição das rotas da aplicação
* `services` — regras e operações da aplicação
* `utils` — funções auxiliares
* `app.ts` — configuração da aplicação
* `server.ts` — inicialização do servidor

## Conceitos estudados

* Desenvolvimento backend com Node.js
* TypeScript
* APIs
* Rotas e endpoints
* Organização de código
* Separação de responsabilidades
* Controllers, Services e Repositories
* Manipulação de dados

## Contexto

Projeto desenvolvido como parte do bootcamp da DIO, acompanhando as explicações e exemplos apresentados durante as aulas.
